# Technical Enhancement Proposal: Advanced Diurnal Scaling and Energy-Balance Closure for ECOSTRESS Collection 3+ L3T JET Evapotranspiration

**Document ID:** RFC-ECOSTRESS-L3T-2026-01  
**Target Product:** ECOSTRESS L3T JET (Evapotranspiration and Evaporative Stress Index)[cite: 1]  
**Category:** Algorithm Theoretical Baseline Document (ATBD) Enhancement  
**Status:** Proposed / Review  

---

## 1. Executive Summary

The ECOSTRESS Collection 3 L3T JET processing pipeline derives daily evapotranspiration (`ETdaily`, in mm day^-1) by upscaling instantaneous latent heat flux estimates ($LE_{inst}$, W m^-2) generated by an ensemble of four energy-balance models (PT-JPL-SM, STIC-JPL, PM-JPL, and BESS-JPL)[cite: 1]. The current operational upscaling algorithm multiplies the median instantaneous latent heat flux by the daylight duration between sunrise and sunset, divided by a constant latent heat of vaporization ($L_v = 2.45 \times 10^6 \text{ J kg}^{-1}$)[cite: 1].

While computationally efficient and robust against missing diurnal meteorological inputs, this uniform "boxcar" scaling formulation introduces systematic orbital-phase biases due to the precessing orbit of the International Space Station (ISS). This proposal details five architectural and physical upgrades to transition the L3T JET upscaling pipeline from uniform integration to an energy-conserving, physically constrained diurnal framework.

## 2. Baseline Architecture and Problem Formulation

### 2.1 Collection 3 Operational Algorithm

The current Collection 3 operational formulation is defined as[cite: 1]:

```text
ETdaily (mm day^-1) = LE_inst * t_daylight / 2450000.0
```

where:
- `LE_inst` is the instantaneous latent heat flux (W m^-2) derived from the median of valid terrestrial models or AquaSEBS for water pixels[cite: 1].
- `t_daylight` is the daylight duration in seconds (`sunset_time - sunrise_time`)[cite: 1].
- `L_v = 2450000.0 J kg^-1` is the fixed latent heat of vaporization[cite: 1].
- `UPSCALE_TO_DAYLIGHT = True` limits integration strictly between astronomical sunrise and sunset[cite: 1].
- `ETuncertainty` is computed as the standard deviation across constituent model daily outputs[cite: 1].

### 2.2 Operational Deficiencies

```
Instantaneous Observation (ISS Overpass)
           ▲
           │          Current Boxcar Upscaling: LE_inst assumed constant over t_daylight
     Flux  │     ┌────────────────────────────────────────────────────────┐
   (W m^-2)│     │                                                        │
           │     │            Actual Diurnal Insolation Curve             │
           │     │                     .---.                              │
           │     │                   /       \                            │
           │     │                  /         \                           │
           │     │                 /           \                          │
           └─────┴────────────────/─────────────\─────────────────────────┴─────► Time
              Sunrise         Overpass        Sunset                     24h
```

1. **Orbital Precession Bias:** ECOSTRESS samples the diurnal cycle across non-sun-synchronous overpass times. Overpasses near solar noon capture peak instantaneous flux, causing uniform integration to overestimate daily ET by 25% to 45%. Morning or late-afternoon overpasses cause underestimation of equivalent magnitude.
2. **Static Energy Assumption:** Instantaneous clear-sky overpasses are scaled over the entire daylight window assuming uniform radiation, ignoring transient afternoon cloudiness or convection.
3. **Absence of Midday Depression / Stomatal Dynamics:** High vapor pressure deficit (VPD) and soil moisture deficits frequently induce afternoon stomatal closure in arid, semi-arid, and water-stressed agricultural biomes. Uniform scaling cannot capture asymmetric diurnal hysteresis.
4. **Omission of Nocturnal Evapotranspiration:** Strict daylight boundary constraints (`UPSCALE_TO_DAYLIGHT = True`) exclude nocturnal transpiration and night-time soil evaporation, which account for 5% to 20% of 24-hour hydrologic flux across global biomes[cite: 1].
5. **Static Thermophysical Properties:** The fixed latent heat of vaporization ($L_v = 2.45 \times 10^6 \text{ J kg}^{-1}$, valid at ~20°C) introduces up to 4.5% systematic error across cold canopy (<5°C) and hot desert (>45°C) conditions[cite: 1].
6. **Small-Sample Ensemble Variance:** The ensemble uncertainty metric ($N \le 4$) relies on standard deviation among models with shared input biases (e.g., common LST and ancillary meteorology) and omits temporal extrapolation uncertainty[cite: 1].

### 3.1 Component 1: Diurnal Radiation and Evaporative Fraction (EF) Scaling

Replace uniform integration with an Evaporative Fraction ($EF$) self-preservation model anchored to sub-daily available energy ($R_n - G$).

#### Formulation:
1. Instantaneous Evaporative Fraction:
   ```text
   EF_inst = LE_inst / (R_n_inst - G_inst)
   ```
   *Bound condition:* $0.0 \le EF_{\text{inst}} \le 1.2$ to eliminate non-physical transfer during low-radiation transitions.

2. Diurnal Integration:
   ```text
   LE_daylight = EF_inst * Integral_{sunrise}^{sunset} [R_n(t) - G(t)] dt
   ```
   Where $R_n(t)$ and $G(t)$ are derived from gridded hourly meteorological reanalysis (e.g., NASA GEOS-FP or ECMWF ERA5-Land) or geostationary satellite radiation products (e.g., GOES-R, Himawari, Meteosat).

3. When ground heat flux ($G$) is unconstrained, fall back to the Shortwave Solar Radiation Ratio ($R_s$):
   ```text
   ET_daylight = (LE_inst / L_v) * [R_s_day / R_s_inst]
   ```
   where $R_{s,\text{day}} = \int_{\text{sunrise}}^{\text{sunset}} R_s(t) \, dt$ and $R_{s,\text{inst}}$ is the downwelling solar flux at overpass time.

### 3.2 Component 2: Afternoon VPD and Asymmetric Stomatal Closure Modifier

To correct for overprediction when overpasses occur before afternoon stomatal closure:

```text
LE_daylight_corrected = LE_daylight * K_stress
```
where $K_{\text{stress}}$ is a diurnal hysteresis attenuation coefficient:
```text
K_stress = 1.0 - beta * max(0.0, (VPD_afternoon - VPD_overpass) / VPD_critical)
```
- $\beta \in [0.1, 0.35]$ is a biome-specific sensitivity parameter calibrated via FLUXNET data.
- $VPD_{\text{critical}}$ is the threshold above which canopy stomatal conductance drops non-linearly (typically 1.5 to 2.5 kPa depending on plant functional type).

### 3.3 Component 3: 24-Hour Hydrologic Balance and Nocturnal Layer

To maintain continuity with Collection 3 while serving hydrological modeling needs[cite: 1], the product will output two distinct daily layers:
1. `ETdaily_daylight`: Direct daylight integration (sunrise to sunset), maintaining backward compatibility[cite: 1].
2. `ETdaily_24h`: Complete 24-hour hydrologic budget.

#### Nocturnal Evapotranspiration Parameterization:
```text
ETdaily_24h = ETdaily_daylight + ET_nocturnal
```
```text
ET_nocturnal = Integral_{sunset}^{next_sunrise} [LE_night(t) / L_v(T_night(t))] dt
```
Where nocturnal latent heat flux ($LE_{\text{night}}$) is parameterized using nighttime vapor pressure deficit ($VPD_n$), surface resistance ($r_{s,\text{night}}$), and nocturnal wind speed ($u_n$):
```text
LE_night = (rho * c_p * VPD_n / (r_a,n + r_s,night)) + delta_n * (R_n,night - G_night) / (delta_n + gamma)
```

### 3.4 Component 4: Thermally Dynamic Latent Heat of Vaporization

Deprecate the constant $2.45 \times 10^6 \text{ J kg}^{-1}$[cite: 1]. Calculate $L_v$ as a function of surface temperature ($T_{\text{surf}}$, in °C) on a per-pixel basis:

```text
L_v(T_surf) = (2.501 - 0.002361 * T_surf) * 10^6  [J kg^-1]
```
For sub-zero pixels (snow/ice or frozen canopy), incorporate the latent heat of sublimation:
```text
L_s = 2.834 * 10^6  [J kg^-1]  (when T_surf < 0.0 °C)
```

### 3.5 Component 5: Biome-Stratified Bayesian Model Averaging (BMA)

Replace the static ensemble median[cite: 1] with a weighted Bayesian Model Averaging scheme.

```text
ET_ensemble = Sum_{i=1}^{M} [ w_i(IGBP, Aridity) * ET_model_i ]
```

| Model[cite: 1] | Forest / Humid Weight | Croplands / Irrigated Weight | Arid / Shrubland Weight |
|:----------------|:---------------------:|:----------------------------:|:-----------------------:|
| PT-JPL-SM       | **0.35**              | 0.20                         | 0.15                    |
| STIC-JPL        | 0.20                  | 0.25                         | **0.35**                |
| PM-JPL          | 0.25                  | 0.25                         | 0.20                    |
| BESS-JPL        | 0.20                  | **0.30**                     | 0.30                    |

*Weights are normalized to sum to 1.0 per grid cell based on MODIS/VIIRS MCD12Q1 Land Cover and Global Aridity Index.*

### 3.6 Component 6: Comprehensive Uncertainty Budget

Replace raw inter-model standard deviation[cite: 1] with a quadrature sum accounting for structural, temporal, and input uncertainties:

```text
sigma_ET_daily = sqrt( sigma_ensemble^2 + sigma_temporal^2 + sigma_driver^2 )
```
- `sigma_ensemble`: Standard deviation across BMA weighted constituent models[cite: 1].
- `sigma_temporal`: Variance introduced by overpass solar zenith angle and diurnal extrapolation:
  ```text
  sigma_temporal = ET_daily * (0.05 + 0.15 * |cos(SZA_overpass) - cos(SZA_noon)|)
  ```
- `sigma_driver`: Propagated uncertainty from input LST, net radiation, and atmospheric boundary conditions.

## 4. Implementation Algorithm & Pseudocode

```python
import numpy as np

def compute_daily_et_v4(
    le_ptjpl: float,
    le_stic: float,
    le_pm: float,
    le_bess: float,
    lst_celsius: float,
    r_n_inst: float,
    g_inst: float,
    r_n_diurnal_hourly: np.ndarray,  # 24 hours of net radiation (W/m^2)
    g_diurnal_hourly: np.ndarray,    # 24 hours of ground heat flux (W/m^2)
    vpd_diurnal_hourly: np.ndarray,  # 24 hours of VPD (kPa)
    overpass_hour: int,
    sunrise_hour: int,
    sunset_hour: int,
    igbp_class: str
) -> dict:
    """
    Advanced Instantaneous-to-Daily ET Upscaling for ECOSTRESS L3T JET.
    """
    # 1. Dynamic Latent Heat of Vaporization
    if lst_celsius < 0.0:
        l_v = 2.834e6  # Sublimation
    else:
        l_v = (2.501 - 0.002361 * lst_celsius) * 1e6  # J / kg

    # 2. Weighted Ensemble Aggregation (Weights mapped via IGBP lookup)
    weights = get_bma_weights(igbp_class)
    models_le = np.array([le_ptjpl, le_stic, le_pm, le_bess])
    le_ensemble_inst = np.sum(models_le * weights)

    # 3. Evaporative Fraction Computation
    available_energy_inst = max(r_n_inst - g_inst, 5.0)  # Bound denominator
    ef_inst = np.clip(le_ensemble_inst / available_energy_inst, 0.0, 1.2)

    # 4. Diurnal Daylight Energy Integration
    # Sum daylight available energy (hours between sunrise and sunset)
    day_slice = slice(sunrise_hour, sunset_hour)
    available_energy_day = np.maximum(
        r_n_diurnal_hourly[day_slice] - g_diurnal_hourly[day_slice], 
        0.0
    )
    # Energy in Joules (1 W * 3600 seconds = 3600 J)
    integrated_e_day = np.sum(available_energy_day) * 3600.0

    # 5. Afternoon Stomatal Closure / VPD Attenuation
    vpd_overpass = vpd_diurnal_hourly[overpass_hour]
    vpd_afternoon = np.max(vpd_diurnal_hourly[day_slice])
    vpd_critical = 2.0  # kPa
    stress_penalty = 0.2 * max(0.0, (vpd_afternoon - vpd_overpass) / vpd_critical)
    k_stress = np.clip(1.0 - stress_penalty, 0.65, 1.0)

    # Daytime ET (mm/day)
    et_daylight_joules = ef_inst * integrated_e_day * k_stress
    et_daily_daylight = et_daylight_joules / l_v

    # 6. Nocturnal ET Flux Integration
    night_indices = np.concatenate([
        np.arange(0, sunrise_hour),
        np.arange(sunset_hour, 24)
    ])
    # Parameterized nocturnal flux (approx. 8% of daytime EF driven by nocturnal vapor pressure gradient)
    vpd_night_mean = np.mean(vpd_diurnal_hourly[night_indices])
    le_night_approx = np.maximum(0.05 * ef_inst * vpd_night_mean * 20.0, 0.0)
    e_night_joules = np.sum(le_night_approx) * 3600.0 * len(night_indices)
    et_nocturnal = e_night_joules / l_v

    et_daily_24h = et_daily_daylight + et_nocturnal

    # 7. Comprehensive Error Propagation
    sigma_ensemble = np.std(models_le) * (et_daily_daylight / max(le_ensemble_inst, 1.0))
    sigma_temporal = et_daily_daylight * (0.05 + 0.1 * abs(overpass_hour - 12) / 6.0)
    sigma_total = np.sqrt(sigma_ensemble**2 + sigma_temporal**2)

    return {
        "ETdaily_daylight": float(et_daily_daylight),
        "ETdaily_24h": float(et_daily_24h),
        "ETuncertainty": float(sigma_total)
    }
```

## 7. Recommendation

Phase 1 (dynamic $L_v$ and solar radiation ratio scaling) should be scheduled for immediate integration into the Collection 3 maintenance release cycle to address overpass-timing biases. Phase 2 (full 24-hour closure and BMA weighting) should be targeted for the Collection 4 reprocessing baseline.
